# 控制台人工验收清单

本清单只覆盖真实使用路径。验收时不要打开微信视频号；混剪登记只在已确认剪映目录、机器配置和素材缓存正确的电脑上执行。

## 1. 登录与设置

1. 首次登录后立即修改默认口令；手机使用局域网地址登录。
2. 打开“设置”，确认爆款库、Obsidian Vault、选题卡目录、Codex 路径和工作目录白名单已显示为预期值。
3. 修改并发限制和本机历史数量，保存后确认它们立刻生效。
4. 修改 App Server、路径、模型或密钥类配置后，确认界面提示“重启控制台后生效”，重启后再检查配置是否生效。

## 2. 选题工作台

1. 从首页新建选题对话，输入一个主题种子，例如“房产、存款和家庭财富”。
2. 确认任务详情显示中文阶段，而不是原始 JSONL；检索词应包含同义词、相邻金融机制和家庭场景，而不只是一条原词搜索。
3. 确认候选结果包含 3—5 个可查看候选、来源引用和差异角度。
4. 选择候选并执行“深化一下”，确认正式选题卡写入配置的 Obsidian 选题卡目录，状态与页面一致。
5. 刷新页面或切换页面后回到同一选题会话，确认候选、消息和任务仍可见。

## 3. 项目与二创

1. 由已深化、可写稿的选题创建项目，并选择目标账号；确认项目归属为所选账号。
2. 或从“已有爆款原文”创建项目，确认原文只属于该项目，不会出现在其他项目资产中。
3. 运行二创任务，确认任务详情能查看发送的任务说明、资产版本、模型与推理强度、中文进度、结果和工程产物。
4. 确认连续文案登记为正式资产；只有显式运行“口播格式化”时才生成口播稿。
5. 编辑或替换上游文案，确认下游资产被标记为过期但旧版本仍可查看。

## 4. Codex 对话与历史

1. 在首页或“Codex 对话”页新建通用对话，确认用户消息、助手回复和阶段以聊天形式显示。
2. 在控制台管理的活动回合中发送引导，确认消息标记为已加入当前任务，而非新建一个重复任务。
3. 查看本机历史，确认桌面版、CLI 和控制台来源可区分，子代理、归档和空会话不会出现。
4. 分别验证“继续原会话”和“复制为新对话”；前者保留原 thread，后者创建独立会话。
5. 尝试删除存在活动任务或项目主会话的对话，确认系统拒绝删除；删除普通空闲对话后确认列表更新。

## 5. 混剪登记

1. 项目只准备连续文案、配音、SRT 和账号背景图；确认混剪不再要求口播稿。
2. 启动混剪前确认机器配置、媒体索引、剪映根目录和已验证音频/转场缓存均可用。
3. 运行任务后，确认先显示制作方案和明文工作区；只有剪映注册回执、目录和哈希验证成功后，才出现 ready 的正式混剪草稿。
4. 人为保留一次安全的注册失败场景，确认页面显示“草稿已生成，注册失败”，保留明文产物并且“只重试注册”不会重新调用 Codex。
5. 在本机回环地址访问项目，确认“在电脑上打开剪映目录”只会打开已登记的可信草稿目录；从手机或代理地址不应提供该动作。

## 6. 手机与恢复

1. 使用手机在局域网打开控制台，确认底部导航、44px 触控目标、输入框安全区和文字换行可正常使用。
2. 在任务运行中刷新或关闭手机浏览器，再次打开后确认任务继续、消息和阶段会回放。
3. 重启控制台后确认未完成任务不会被重复创建；已完成任务和已登记产物仍可查看。
