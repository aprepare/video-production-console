# 控制台人工验收清单

本清单只覆盖真实使用路径。验收时不要打开微信视频号；混剪登记只在已确认剪映目录、机器配置和素材缓存正确的电脑上执行。选题工作台已从界面移除，不要再验「给我选题」。

## 1. 登录与设置

1. 首次登录后立即修改默认口令；手机使用局域网地址登录。
2. 打开「设置」，确认二创地址/模型/密钥、Skills 根目录、剪映 machine profile、媒体路径、生图模型和素材库分析模型显示为预期值。
3. 修改并发限制，保存后确认它立刻生效。
4. 修改路径、监听地址、模型或密钥类配置后，确认界面提示“重启控制台后生效”，重启后再检查配置是否生效。

## 2. 制作方式首页

1. 打开 `http://127.0.0.1:2030/`，看到混剪制作、电影混剪、图文制作三张卡片。
2. 前两张进入 `/projects` 同一套工作台；图文进入 `/image-projects`。
3. 首页不应出现选题工作台或「给我选题」。

## 3. 项目与二创

1. 从看板新建项目并选择目标账号；确认项目归属为所选账号。
2. 在工作台粘贴同行原文，点「保存原文并开始二创」。确认走 OpenAI 兼容接口，不走 Codex CLI。
3. 任务完成后确认 `continuous_script` 与发布包装记为正式资产。
4. 编辑或替换上游文案，确认下游资产被标记为过期但旧版本仍可查看。
5. 「打回重做」走 `remix.review`；查看弹窗可直接改稿。

## 4. 任务交互与恢复

1. 首页不应出现「Codex 对话」入口，项目页也不应出现独立对话摘要或本机历史。
2. 生产任务需要追问时，在任务详情中回答，确认回复进入当前任务而不是创建重复任务。
3. 重启控制台后，确认正在运行或等待输入的正式任务可恢复，已完成任务和项目资产仍可读取。
4. `GET /api/chat/sessions` 与 `GET /api/codex/history` 不应再提供独立对话/历史 API。

## 5. 素材库与混剪登记

1. 项目只准备连续文案、配音、SRT 和账号背景图；确认混剪不再要求口播稿。
2. 设置里的 FFmpeg/FFprobe、素材库目录与视觉/embedding 要能用；未配外部图库密钥不得挡住本地建库。
3. 从首页打开「素材库」，点「开始建库」。应跑扫描、切镜、打标、向量。看「就绪镜头」，不要只看就绪状态。识别全失败应提示，不得假装成功。
4. 建库完成后点「开始风景混剪」或「开始电影混剪」，确认系统自动从 `catalog.db` 检索，不必手工选片。风景线只出风景/景观；电影线按口播概念，不过滤成风景。
5. 运行任务后，确认先显示制作方案和明文工作区。v2 日产：缩放约 1.2、字幕关闭、无窗内白字标题。只有剪映注册回执、目录和哈希验证成功后，才出现 ready 的正式混剪草稿。
6. 「重做混剪」再发一条任务，不删旧草稿。
7. 人为保留一次安全的注册失败场景，确认页面显示“草稿已生成，注册失败”，保留明文产物并且“只重试注册”不会重新调用 Codex。
8. 在本机回环地址访问项目，确认“在电脑上打开剪映目录”只会打开已登记的可信草稿目录；从手机或代理地址不应提供该动作。

## 6. 手机与恢复

1. 使用手机在局域网打开控制台，确认底部导航、44px 触控目标、输入框安全区和文字换行可正常使用。
2. 在任务运行中刷新或关闭手机浏览器，再次打开后确认任务继续、消息和阶段会回放。
3. 重启控制台后确认未完成任务不会被重复创建；已完成任务和已登记产物仍可查看。

## 7. 图文模式

1. 在设置中填写测试用生图 Base URL、模型和 Key；保存后重新打开设置，确认 Key 只显示“已配置”，接口响应和浏览器页面都不包含原值。
2. 从制作方式首页进入「图文制作」`/image-projects`，粘贴已定稿文案，一键生成；确认没有创建二创或混剪任务。刷新应留在当前项目。
3. 阶段失败或重启后出现「继续生成」，已成功的图不重做。
4. 全部 ready 后「图文标题及描述」可编辑 5 条候选并打包 ZIP。
5. 高级手动模式 `/image-projects/advanced` 仍可分段建议 → 确认 → 提示词。
6. 删除项目时必须出现影响范围确认；取消确认不删除，确认后项目和生成图片不可再访问。
