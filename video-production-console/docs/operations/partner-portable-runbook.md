# 伙伴便携版操作说明

本说明只覆盖合作伙伴电脑上的安装、首次配置、日常使用、路径修复、更新和回滚。不要向合作伙伴转发任何服务地址、密钥或内部错误原文。

## 1. 收到软件后怎么打开

1. 同时拿到两样东西：伙伴安装程序 `video-production-console-partner-<version>.exe`，以及单独交付的风景素材文件夹。
2. 双击 EXE。不要右键「以管理员身份运行」，也不要关闭 Windows 对未知发布者的提示后去改系统权限。
3. 如果 SmartScreen 显示「Windows 已保护你的电脑」或「未知发布者」，选择「更多信息」，再选择「仍要运行」。这是未签名安装包的预期提示，不是病毒报警。
4. 程序会解压到当前 Windows 用户的本地应用数据目录，并自动打开本机控制台。不需要单独安装 Python、FFmpeg 或 Codex。

## 2. 校验安装包

在 EXE 同级目录打开 PowerShell，把文件名换成实际版本后执行：

```powershell
(Get-FileHash .\video-production-console-partner-0.1.0.exe -Algorithm SHA256).Hash.ToLowerInvariant()
```

把结果和随包提供的 `.sha256` 文件内容对比。不一致就停止安装，重新索取安装包。

## 3. 首次激活和本机目录

1. 打开后先进入伙伴授权页。把一次性激活密钥完整粘贴进去，只激活一次。
2. 授权通过后进入本机配置：选择「剪映草稿目录」和「风景素材目录」。
3. 剪映草稿优先使用本机已有的剪映工程目录；检测失败时再手动选择可写目录。不要选磁盘根目录。
4. 风景素材目录必须是单独收到的素材根目录，并且里面有 `originals`。不要选择 `catalog.db`，也不要把素材复制进软件目录。
5. 点击「检查并继续」后，界面会显示「正在建立本机素材索引」。等待程序自动重启，不要手动结束进程。
6. 重启后即可进入制作界面，按日常流程创建项目。

## 4. 日常使用

1. 以后直接双击同一份或更新后的 EXE。已激活的电脑不需要再次输入密钥。
2. 项目、配音、图片和剪映草稿都保存在本机。风景素材始终从你指定的素材目录读取。
3. 不要把 `machine-profile.json` 或激活信息复制到另一台电脑。

## 5. 素材或草稿路径被移动后

1. 再次打开软件。如果本机配置不完整，会回到目录向导。
2. 重新选择移动后的剪映草稿目录和风景素材目录。
3. 等待自动重启。已有项目不会因为重新选择路径而被删除。
4. 不要手工改数据库，也不要拷贝旧电脑的 `catalog.db`。

## 6. 更新

1. 向发放方索取新的 EXE，并再次核对 SHA-256。
2. 用新 EXE 覆盖旧文件后双击运行即可。启动器会安装新版本，并保留上一版以便回滚。
3. 不要删除本地数据目录。项目和授权会留在原处。

## 7. 回滚

1. 如果新版本无法启动，改回运行上一个可用的 EXE。
2. 启动器会切回上一版已校验的程序，本机项目和素材路径保持不变。
3. 回滚后如果仍提示本机目录无效，按第 5 节重新选择路径。

## 8. 常见提示

| 现象 | 处理 |
| --- | --- |
| SmartScreen 提示未知发布者 | 「更多信息」→「仍要运行」。不要寻求管理员提权。 |
| 激活失败 | 核对密钥是否完整、是否已在别的电脑用过。不要把错误原文发给其他人。 |
| 目录检查失败 | 确认草稿目录可写、素材目录含 `originals`，且都不是磁盘根目录或快捷方式。 |
| 混剪立刻提示没有可用镜头 | 风景素材根目录必须含 `originals`，且里面有 ≥10 秒的**自然/天气风景**视频，或素材包自带只含风景分类的 `00_INDEX/media_index.json`。城市、财经、宇宙镜头不会再进片。选错成空目录或只选了子文件夹都会失败。重新选对素材根目录后等程序重启，再点混剪。 |
| 自动重启后没有进入主界面 | 再双击一次 EXE。若仍停在配置页，重新选择路径。 |
| 更新后打不开 | 运行上一版 EXE 回滚，然后重新索取安装包。 |
