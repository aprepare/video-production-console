# 混剪草稿登记与验收

控制台把“生成草稿”和“让剪映识别草稿”拆成两个可恢复步骤。这样登记失败或电脑中断时，已经生成的混剪内容不会丢失，也不需要重新运行 Codex。

## 草稿如何成为正式资产

1. **生成明文草稿**：混剪任务先在受控工作区写出可检查的草稿文件。任务详情显示“明文草稿已生成”。
2. **登记到剪映**：控制台把现有明文草稿登记到设置中指定的剪映草稿目录。此时显示“正在登记到剪映”。
3. **主机验证**：登记程序在本机检查登记路径和回执，确认剪映可读取的目录已经形成。
4. **登记正式资产**：验证通过后，任务显示“已登记为正式资产”，并列出正式草稿名称和剪映路径。这个正式资产仍然只属于当前视频项目。

“明文草稿”是可恢复的中间产物；“正式草稿”是已经通过本机登记验证、可交给剪映继续编辑的项目资产。两者不能混为一项。

## 失败、中断与只重试登记

- **登记失败**：明文工作区会保留。任务详情显示登记错误和“只重试剪映登记”按钮。
- **登记中断**：例如控制台重启或电脑意外关机。再次打开任务详情后，保留的明文草稿仍可用于重试。
- **只重试剪映登记**：只重新执行登记和主机验证，不重新生成草稿，也不会重新运行 Codex。适合修正剪映目录、磁盘权限或机器配置后使用。
- **已登记**：任务详情应显示正式草稿文件名及剪映路径；项目资产区应能看到对应草稿。

若登记仍失败，先检查“设置”中的剪映草稿目录和混剪机器配置是否指向当前电脑的有效路径，并确认当前账户对目标目录有写入权限。

## 为什么控制台不自动启动剪映

自动启动桌面软件会抢占焦点，并可能触发剪映自己的升级、登录、草稿迁移或恢复弹窗；这些行为无法由控制台可靠判断，也会让局域网手机操作变得不可预期。因此控制台只负责生成、登记和验证文件，不代替用户启动或操作剪映。最终打开草稿的动作由用户在本机完成。

## 本机打开目录的访问限制

“打开资产目录”是本机桌面动作，只支持在控制台所在电脑上用浏览器直接访问 `localhost`、`127.0.0.1` 或 `[::1]` 后操作。服务会同时核对浏览器同源元数据、请求来源、浏览器访问地址和本地监听地址；缺少浏览器同源头或任一地址不是回环地址时，固定拒绝该动作。

不要为此动作配置反向代理、端口转发或网络隧道。即使代理或隧道最终转发到本机，控制台也会拒绝打开目录；局域网手机和其他电脑只能查看界面提供的规范路径与安全目录清单，不能触发本机资源管理器。

## 用户最终测试

1. 在电脑上启动控制台，并确认手机和电脑连接同一个受信任的局域网。
2. 用手机浏览器打开控制台地址，登录后选择一个测试项目；确认页面顶部或项目抽屉始终能看到当前项目标题。
3. 确认项目已经有文案、配音、SRT 和固定背景图，然后点“生成混剪”。
4. 打开任务详情，观察状态依次经过“明文草稿已生成”“正在登记到剪映”“已登记为正式资产”。
5. 记录界面显示的正式草稿名称和剪映路径。在电脑上手动打开剪映，确认能找到并打开该草稿。
6. 回到控制台，确认草稿出现在当前项目的专属素材中，且其他项目不会显示它。
7. 失败路径验证：使用一个无效或暂不可写的登记目录触发失败，恢复正确设置后点“只重试剪映登记”；确认没有重新生成草稿、没有重新运行 Codex，最终仍登记成功。
8. 中断路径验证：在登记阶段关闭并重新启动控制台；确认任务显示已中断或可重试，明文草稿仍然存在。

局域网访问只应开放给受信任设备。若管理员认证尚未启用，不要把控制台暴露到公共 Wi-Fi 或公网。
