## 改动

- `scenic_model.go`：受限候选复选、并发上限、超时、缓存、返回 ID 校验、来源和近似画面复核。
- `scenic_semantic.go`：模型参与主线；默认开头 6–8 秒、正文 6–9 秒、1 倍速、约 45% 叠化；第一处边界有叠化；部分镜头有轻微推拉。
- `editorial.go`、`editorial_quotes.go`：先按原文标点提取完整短句，核对字幕原句后让模型挑重点。不能编写新数字或把字幕半句直接包装成结论。
- `shot_select.go`：修正选镜提示词、候选副本处理和 Unicode 截断、重复意图响应过滤。
- `catalog_clients.go`、`task_manifest.go`：风景选片读取冻结的任务模型选择。
- `tools/jianying_editorial/editorial_layers.py`：可编辑重点文字、独立卡片底图、原生羽化蒙版、低音量提示音及实际草稿质检。
- `scripts/install_editorial_skill.py`：同步安装并备份 Python 计划解析器、执行器和校验器。新计划声明转场挂在边界前的片段；旧计划保持原契约。
