# 创作工作室前端优化设计

用户已选择视觉与操作一起优化。沿用文案与混剪、图文制作两个工作空间，覆盖登录、账号总览、项目详情、设置与共用弹窗；不恢复文档柜或 AI短片。

## 视觉与布局

创作台用于每天处理原文、审稿和生产，主要任务是编辑与判断状态。采用冷灰工作面 `#f3f5f9`、白色编辑面 `#ffffff`、墨蓝正文 `#20283f`、灰蓝说明 `#67718b`、蓝色操作 `#2954dc`、灰蓝边线 `#dde2ec`。成功与失败仍各有语义颜色。标题使用本机 Segoe UI Variable Display / Microsoft YaHei UI，正文使用 Segoe UI / Microsoft YaHei，编号与时间使用 Cascadia Code / Consolas。深色模式替换语义色，不使用亮底暗字的残留卡片。

桌面采用窄导航 + 历史栏 + 制作步骤 + 编辑区。工作室的识别元素是贯穿制作阶段的进度轨道，与实际当前阶段同步；其余区块保持安静。导航保留文字到 1180px，较小桌面保留图标及可访问名称；手机顶部导航。步骤从宽大的网格卡片改为纵向紧凑列表，手机可横向查看步骤。仅使用 Lucide 图标，悬停与焦点变化在 150ms 左右，尊重 reduced-motion。此工作台不引入装饰媒体、网络字体或渲染库。

## 操作改进

图文制作只保留一个页面标题，把已填写文案、日常参数与项目库分区。项目库支持标题搜索和状态筛选，区分没有项目与没有匹配结果，可清除筛选；新控件只在本地过滤已有列表，不发生成请求。文案输入显示字符数；原文、草稿、模型默认值和已有高级参数保持原行为。历史搜索的无结果提示要准确，折叠按钮暴露展开状态。

全站共享圆角、输入框、焦点、状态色与滚动条，设置保存区保持可见。键盘提供跳到工作区链接。手机页面不横向溢出，表单和按钮不因固定高度被截断。保留现有所有后端接口、数据、用户改动和视频工程。

## 验证

新项目库执行 UI 搜索与筛选测试；原有文案、图文、导航、设置与项目相关测试通过。执行类型检查及前端嵌入构建。独立浏览器测试检查桌面、手机、深色模式、设置和主要操作；保存截图。最后重编 Go 程序并更新本地服务，检查健康与最终前端资源。
