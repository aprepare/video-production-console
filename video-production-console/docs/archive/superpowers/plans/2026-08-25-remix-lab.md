# 二创进化台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在控制台加独立页 `/remix-lab`：一篇对标可多模型、每模型跑 1～3 次，按篇批注，可把某篇采用到已有风景混剪项目；默认 rewrite 写手禁空收尾。

**Architecture:** 不走 `remix.standard` 任务去重。`internal/remixlab` 建实验行后，每稿独立目录调用 `openaicompat.Run`（测试注入 fake runner）。HTTP `/api/remix-lab/*` 读 `Runtime()` 回落地址/密钥。前端新页轮询实验详情。采用调用现有 `assets.Service.SaveProjectAsset` + `AddAsset`。

**Tech Stack:** Go、SQLite migration、React 19 + Vite、Vitest。不接任务 WebSocket。

## Global Constraints

- 批注只存，不按批注自动改提示词。
- 一次对标 = 一次实验，历史全留。
- 独立页，不复用项目二创对比，不挂 `ModeHome` / `ImageVideoStudio` / 选题。
- 采用只写已有风景混剪项目的 `continuous_script`，不新建项目，不覆盖 `source_script`，不导入 titles。
- 写手本轮只禁空收尾：`就这些` / `就这样` / `好了` / `就说到这儿`；戳改为 `语感回流 2026-08-25 禁空收尾`。
- `rewrite_sharp` / `copy` 不改。不修 `TestWriterPromptSharpEmphasizesImpact`。
- 每槽次数 1～3，最多 4 槽，原文 1～20000 字，批注最长 2000 字。
- 进化台 LLM 并发单独为 2，不改 `max_codex_concurrency`。
- GET 永不回密钥明文，只回 `api_key_configured`。
- 产物目录：`{DataRoot}/remix-lab/{experiment_id}/{run_id}/`。
- `remix_prompt_style` 固定 `rewrite`。
- 不要 git commit，除非用户在对话里明确要求。
- 不要把密钥写进测试断言以外的日志或用户可见文案。

```go
var (
    ErrInvalidSource   = errors.New("source must be 1 to 20000 characters")
    ErrInvalidSlots    = errors.New("slots must be 1 to 4")
    ErrInvalidRunCount = errors.New("run_count must be 1 to 3")
    ErrMissingModel    = errors.New("model is required")
    ErrMissingAPIKey   = errors.New("remix api key is not configured")
)
```

解析规则（按顺序）：

1. `model` 去空后必填。
2. `run_count` 默认 1；不在 1～3 则 `ErrInvalidRunCount`。
3. `base_url` 空 → `Runtime.RemixBaseURL`。
4. `api_key` 非空 → `protector.Protect` 后写入该槽 ciphertext。
5. `api_key` 空且 `PresetIndex != nil` → 读预置 JSON 对应下标的 ciphertext（已是密文，原样拷进槽）。
6. 否则用 `Runtime.RemixAPIKey`（不写进槽 ciphertext，槽留空表示回落）。
7. 若解析完 key 仍空 → `ErrMissingAPIKey`。
8. `source` 用 `utf8.RuneCountInString` 判 1～20000。
9. title = 原文去掉换行后的前 24 个 rune；空则 `实验` + `now.Format("01-02 15:04")`。
10. `prompt_stamp` = `openaicompat.RewritePromptStampStable`。

预置 JSON 形状（密文 base64，与 settings 一致）：

```json
{"slots":[{"base_url":"...","model":"...","reasoning_effort":"","run_count":2,"api_key_ciphertext":"..."}]}
```
