# 二创提示词编辑与审稿格式修复

用户授权修复审稿、移除参考稿、导出全部提示词并提供系统内编辑。最新指令：不写或运行测试、不调用模型试跑，由用户验证。

1. 原始错误定位：review_reply_raw.txt 包含 Let + JSON 围栏和未转义英文引号（包含连续双引号）。新增独立格式修复器，只修转义，不补正文或审稿结论；仍按原结构与语义约束解析。
2. 新建默认图取消参考稿。当前全局及账号工作流仅移除 reference 角色节点并桥接连线；先保留原 JSON 备份，历史运行不改。
3. 新入口 GET/PUT workflow-prompts 直接读取/保存当前账号工作流。写手节点 system/user 优先实际执行；每轮冻结解析后的写手文本。公共 editorial_rules 显式可编辑，空字符串表示停用，输出格式分开附加。审稿 user_template 同步运行和打回路径。
4. 新提示词对话框提供公共规则、写手、审稿及实际前置节点，下载 Markdown；保存期间锁定编辑，错误保留输入。Canvas 后续保存必须保留公共规则。
5. 导出有效全局与各账号全部提示词、备用角色和提示词库。只执行必要编译及启用程序，不运行测试、浏览器测试或模型请求；交付明确由用户试用。
