版本：**文案进化台 2026-08-19 中老年定稿**

代码入口：

| 位置 | 作用 |
|---|---|
| `internal/agentruntime/openaicompat/run.go` `RewritePromptStamp` | 版本戳（不发给模型） |
| 同文件 `buildWriterPrompt` | rewrite 系统提示词 |
| 同文件 `buildWriterUser` | rewrite 用户侧（先锁机器，钩子必须五十岁以上一听就懂） |
| 同文件 `buildWashPrompt` | 洗稿路径，**未改** |

控制台默认走 rewrite。`remix_prompt_style=wash` 才走洗稿。

## 相对控制台旧版加了什么

1. **先锁六件套机器**：钩子 / 未揭晓答案 / 数字或历史证明 / 普通人差距 / 情绪升级 / 收口催促。一条都不能丢。
2. **关键数字必须原词**。禁止改成「很多」「心惊的数」「差不多」。
3. **对仗钩子不能写软**。原稿对仗打脸，新稿第一句还得是对仗打脸，两边都是大白话。
4. **【中老年听得懂】**：听的人是 45–65 岁。开场禁止锚点、换锚、换毛、货币、结汇、印钞、认知、红利、风口、阶层、史诗级、逻辑、趋势、下半场。
5. **禁止按「第 N 个难题」对照译文**。中间必须换切口（现场 / 人物 / 一个动作）。
6. **密度失败标准写死**：钩子要解释才懂、开场黑话、数字糊了、写顺了、对照没了、降温成家庭理财课 → 整稿失败。

落盘仍以 `continuous_script` 为准。模型可额外返回 `machine`（六句锁机器）；`parseRemixDraft` 忽略未知字段。

`finance-viral-remix/SKILL.md` 仍只作 ≤1800 字补充，不要在 skill 里写死换锚 / 法拍房等现成情节。

## 试写记录（文案进化台，不进本仓库）

- 法拍房 / 五个要命难题：旧稿软钩子、数字形容词化；收紧后过关。
- 存款蒸发 / 20500 亿：五项检查过关。
- 人民币换锚：加中老年规则后，钩子改成生活词（开厂发了 / 买房翻了 20 倍），不再把「换锚」扔第一句。

口播建议模型：`grok-4.6`，思考强度 `high`。密钥不要写进仓库。
