## 最终行为

- 默认二创流程：对标原文 → 二创策划 → 写手 → 机械自检 → 审稿终审 → 定稿与发布包。沿用 hook 节点 ID；默认移除 ammo，facts 与 hook_library 保持不接入。
- 策划统一提供核心问题、开头三句推进、正文推进、一次中段评论、真实课程承接、结尾动作。课程依据用户提供的九节课大纲，避免承诺课程未包含的投资时点或赛道答案。
- 写手和审稿使用同一份冻结策划；正文须回应开头的问题。中段要求一次自然、相关的评论引导，点赞不替代评论。
- 课尾承接当篇内容，选择一至两个课程用途说明购买理由，最后一句落到橱窗动作。保留原有长度和提及次数约束。
- 机械规则仅增加结构提醒，不用关键词判断语义通过，不新增硬失败门槛。默认路径不再隐含要求事实核查节点。
- 全局和七个账号已同步。模型、推理强度、Fast、生产设置保持不变。新建及同项目重跑使用新配置；旧稿和旧运行快照保留。
