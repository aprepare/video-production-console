# 账号与历史项目联动修复

用户发现顶部选择云中观局，但混剪闸门显示认知研习。

## 原因与范围

数据库内两个项目的归属及生产账号一致，错误来自页面上下文：顶部沿用浏览器账号偏好，历史实验详情未同步所属账号；切换顶部账号后仍停留在原实验路由；无生产记录的新运行可能沿用上一运行的生产状态。

- 实验详情 API 返回项目所属 `account_id`，包括明确的全局空值。
- 打开历史实验时同步顶部账号；切换账号退出原实验并清除旧详情。
- 用选择序号阻止已发出的旧详情请求覆盖用户的新账号选择。
- 仅向工作流传递当前路由对应的详情，恢复运行时明确清除缺失的生产状态与旧闸门账号。
- 保留混剪闸门手动指定其他账号的能力。未修改数据库中的项目归属、文案或之前删除事实节点的配置。
