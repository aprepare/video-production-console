# Fast 加速开关

按用户确认，Fast 申请加速通道，保留所选模型和 reasoning_effort。

- 模型配置弹窗、工作流写手、情报 agent 和审稿节点新增 Fast 按钮。
- 开启发送 service_tier=priority；手动关闭发送 default；旧配置空值省略参数，保持原有请求。
- 写手未单独设置时继承模型档 1，可手动关闭覆盖，也可恢复跟随默认档。
- 工作流情报和审稿单独设置 Fast，不跟随写手；旧固定管线的审稿沿用槽位设置。
- 写手自检返工、发布字段修复沿用写手设置；审稿打回沿用历史审稿节点快照。
- 预设、实验槽位及工作流快照持久化；新增 SQLite service_tier 列，已有数据默认空值。

官方参数依据：https://developers.openai.com/api/docs/guides/fast-mode 。实际加速、是否支持和计费由上游通道决定。此开关不会把自定义模型名中的 fast 当成已启用的加速参数。

验证：四个后端包测试和 go vet 通过；前端组件/页面测试与 TypeScript 检查通过；前端内嵌构建和 Go 程序构建通过。新增测试覆盖 HTTP 请求保留模型/强度、关闭覆盖、节点独立、写手返工、审稿请求、预设 API 保存与非法值、历史槽位与工作流快照。未调用真实付费上游验证时延。

程序更新：dist/video-production-console.exe；更新前备份为 dist/video-production-console.before-fast-时间戳.exe。下次启动生效。
