# 视频生产控制台 UI 重构

用户已选择推荐方向：深蓝灰导航、明亮工作区、青蓝色强调和轻量动效；操作逻辑优先。采用当前工作树，保留已有后端、Fast 模式和其他 AI 改动。

## 视觉与信息结构

固定主导航：文案与混剪 `/`，图文制作 `/image-projects`，AI短片 `/ai-shorts`。复用现有 history 路由，不新增独立项目看板、不开放已屏蔽模式。设置、主题、退出归全局导航；账号切换和当前内容工具保留在所属页头。桌面导航宽208px；平板压缩、手机横向导航。

配色：导航 #14243B，画布 #F4F7FB，面板 #FFFFFF，正文 #203148，强调 #087FA4，边框 #DFE7F1。使用既有 --ds-* 与兼容 token，统一由全局设计层维护；暗色模式保持可用。标题使用 Segoe UI Variable Display / Microsoft YaHei UI，正文 Segoe UI / PingFang SC / Microsoft YaHei，数值 Cascadia Code / Consolas。字号主体14px、标题24～28px。Lucide 图标，不使用emoji。

特征交互是生产进度带：用明确阶段和当前状态引导下一步，画布作为可检查的执行过程。保留节点详情，减少大面积留白；配置收在次级入口。动效150～220ms，仅用于进入、焦点、展开和运行状态；尊重 prefers-reduced-motion。

## 操作约束

- 定稿有修改时，保存成功后才能开始混剪；失败保留编辑。确认、重试、导出、采用等按请求生命周期禁用，防重复提交。
- 各账号原文草稿独立恢复；切账号不丢未提交原文，不吞掉待保存配置。
- 原文创作→审稿定稿→确认账号并生产→草稿交付→人工确认已发布。草稿完成不等于发布完成。
- 导入分步失败时保留已创建项目引用，提供重试；跨账号采用需显示账号身份。
- 加载、空、失败三态分开，错误带重试；有未保存指标时刷新不得覆盖。
- 保留任务URL恢复、浏览器前进后退、已有焦点陷阱和弹层层级。任务回答失败保留文字并给就地反馈。

## 验收

覆盖主要路由、工作流创建/运行/审稿、项目生产、图文、AI短片、账号与设置、任务和素材弹层；不触发真实模型付费任务或实际发布。运行 typecheck、lint、相关并全量前端单测、构建验证；真实浏览器检查桌面/窄屏/暗色/键盘/减弱动效。最后嵌入前端并重建后端，运行中服务需确认空闲后切换，不中断任务。
