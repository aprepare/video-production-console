# 视频生产控制台 · 使用说明

面向日常使用的管理员 / 创作者。技术边界与开发验证见 [AI 接手说明](AI-HANDOFF.md)。

## 1. 启动与首次配置

1. 确认本机已安装并可执行：`codex --version`、Go、Node/npm（仅开发时需要）。
2. 日常主路径是「粘贴同行原文 → 二创」，不依赖爆款库。爆款库地址仅留给旧检索回落。
3. **首次安装**（数据库尚无管理员）启动前必须设置环境变量：

```powershell
$env:VIDEO_CONSOLE_INITIAL_PASSWORD = "你的初始口令"
.\dist\video-production-console.exe
# 或开发：go run .\cmd\console
```

4. 浏览器访问 `http://127.0.0.1:2030`。
5. 首次登录后立即修改密码。
6. 在「设置」中配置 Skills 根目录、剪映 machine profile、媒体路径、二创模型、生图模型和素材库分析模型。路径、监听地址、模型/密钥类配置保存后可能提示需重启。

### 图文生图设置

- `生图服务地址`：OpenAI 兼容 Base URL，可编辑。HTTPS 更安全；系统允许在用户明确接受风险时保存 `http://` 地址，但 API Key 会随请求以明文传输。
- `生图模型`：默认 `gpt-image-2`，可按供应商实际模型名修改。
- `同时生成图片数`：默认 3，可选 1–18。
- `每张图片最多请求次数`：默认 2，可选 1–4。这个数字包含第一次请求；设为 2 表示失败后最多再请求一次。瞬时错误（限流、网关、断连、超时）会自动重试，参数错误、鉴权失败和取消不会。
- `默认图片比例`：默认 `3:4`；可选 `3:4`、`4:3`、`9:16`、`1:1`。
- `默认视觉风格`：默认「财经纪实插画」，也可选择赤墨、旧报档案、账本调查等预设。
- `生图 API Key`：只在后端经 OS 密钥保护后保存。设置页不会回显原文；留空表示保持现有值。不要把真实 Key 写进 README、截图、日志、工单或版本库。
- 分段建议另外依赖「图文文本模型地址 / 图文文本模型 / 图文文本思考强度 / 图文文本模型 API Key」。思考强度可留空（请求不带该字段），也可选 `low` / `medium` / `high` / `xhigh` / `max` / `ultra`。未单独配置文本模型时会回落 Grok 文本设置；两套都空就会分段失败。这和生图 Key 不是同一套。

### 局域网访问

- 新安装默认只监听 `127.0.0.1:2030`（本机）。
- 需要手机访问时，在设置中显式改为局域网 IP 或 `0.0.0.0:2030`，并在提示重启后重启控制台。
- 不要暴露到公网或公共 Wi-Fi。

## 2. 登录与账号

- 登录后选择或新建账号；每个账号可配置固定背景图。
- 项目归属于账号；资产与任务按项目隔离，不会串到其他项目。

## 3. 五阶段生产流程

打开控制台先进入制作方式首页：混剪制作、电影混剪、图文制作。混剪与电影混剪进入同一套项目工作台，用工作台里的按钮区分。图文是独立线：

- 需要真实视频素材、配音字幕和剪映草稿时使用**混剪模式**；
- 已经有最终文案、只需要按文案生成有序内容图时使用**图文模式**。

### 3.1 图文模式

默认地址是 `/image-projects`，进入一键生成工作台。需要改分段或逐条改提示词时，点「高级手动模式」进入 `/image-projects/advanced`。项目详情都在 `/image-projects/{项目ID}`，刷新浏览器会留在当前项目，不会回到制作方式首页。

**一键生成**

1. 进入图文制作后，只需粘贴已经定稿的完整文案。不用填项目名称；名称由文本模型根据文案生成，生成后仍可在详情页改并保存。
2. 右侧可改思考强度、比例、风格、并发和图片模型。「高级参数」里是每张图的总请求次数（默认跟设置走，可按项目覆盖）。
3. 点「开始生成图片」。页面进入详情并显示四阶段进度：分析文案 → 生成提示词 → 生成图片 x/n → 完成。关掉浏览器或刷新不会取消后台任务。
4. 阶段失败或控制台重启后，详情页会出现「继续生成」，从最后一个已完成检查点接着跑，不会重做已经成功的图片。
5. 允许部分成功：成功的图可预览；失败项留在原位，显示错误和「重新生成」。一键完成后默认隐藏原文和提示词，需要时再点「显示高级编辑」。
6. 「图文标题及描述」在「打包下载」左侧。弹窗左侧 5 条候选，右侧改标题（最多 22 字）和描述（最多 1000 字）。每条描述末尾应有 3–5 个与内容相关的话题，例如 `#存款 #财富管理 #思维提升`。可分别复制标题、描述或全部，再保存当前候选。

**高级手动模式**

1. 在 `/image-projects/advanced` 填写项目名称并粘贴文案。系统只按顺序拆分卡片，不会二创或改写观点。
2. 「建议张数」可留空，先让文本模型按语义切段；也可以填 1–18。再选比例、并发、风格、思考强度、尝试次数和可选文本模型。
3. 点「生成分段建议」。用的是设置里的**图文文本模型**，不是生图 Key。第一张固定为封面。模型若只是去掉首尾空格或包了一层思考/代码块，系统会尽量还原原文；跳句或改写仍会失败。
4. 核对每段原文和标题，确认后点「确认分段并生成提示词」。
5. 之后与一键项目共用画廊：可改图片名称、原文、提示词，单张或批量补生成。保存提示词后该卡片回到“等待生成”。
6. 「生成缺失图片」只处理尚未成功的卡片。图片成功后显示实际尺寸。`3:4`、`9:16` 请求竖版 `1024×1536`，`4:3` 请求横版 `1536×1024`，`1:1` 请求 `1024×1024`。全部 ready 后「打包下载」才会启用。
7. 删除图文项目会同时删除数据库记录和已生成图片，页面必须二次确认。

> 图文模式不会生成时间轴、字幕、配音或剪映草稿。需要这些交付时仍走混剪模式。

## 4. 五阶段混剪生产流程

工作台按资产自动推导阶段：

1. **文案生成**：需要正式连续文案 `continuous_script`
2. **配音字幕**：需要配音、SRT、账号背景图
3. **智能混剪**：生成混剪草稿（明文 → 剪映登记）
4. **审核**：已有混剪草稿或可选成片
5. **已发布**：人工确认发布状态

界面会提示「建议下一步」。不要为了跳阶段而手动改库。

## 5. 同行原文二创（推荐主路径）

控制台不再提供独立 Codex 对话或本机历史入口。文案必须通过正式项目任务产出，才能写入项目资产并解锁下一步。

正确流程：

1. 打开项目 → 进入「文案生成」
2. 在「同行原文」框粘贴全文
3. 点击「保存原文并开始二创」
4. 系统会：
   - 保存为项目资产 `source_script`
   - 创建正式任务 `remix.standard`（绑定该原文版本）
5. 任务完成后登记 `continuous_script`，自动进入「配音字幕」

说明：

- 按钮显示「正在保存/启动…」或任务进行中时，表示已有活动二创任务，请等待或打开任务详情查看进度。
- 若原文已保存但任务失败，可在正文未改动时再次点击，系统会优先重试建任务而不是重复上传。
- 二创走设置里的「二创服务地址 / 二创模型 / 二创 API 密钥」，不走 Codex CLI。思考强度写在模型名里。
- rewrite 系统提示词版本：`文案进化台 2026-08-19 中老年定稿`（`RewritePromptStamp`，详见 [REWRITE-PROMPT.md](REWRITE-PROMPT.md)）。钩子必须五十岁以上一听就懂，数字原词留下。洗稿（wash）提示词未改。
- 界面不再提供选题工作台。不要找「给我选题」。

## 6. 选题卡路径（已停用）

选题入口已从界面移除。不要混用旧的选题卡工作流。需要写稿时只粘贴同行原文。

## 7. 混剪与剪映

### 配音与字幕的两种入口

- **自动配音**：点击工作台的「生成配音与字幕」，调用 `POST /api/projects/{id}/narration`。系统读取当前 `continuous_script`，通过已配置的火山语音服务同时生成 `narration` 和词级来源的 `subtitle_srt`。这条路径要求设置中已填写语音 API Key 与音色 ID。
- **手动上传配音**：点击配音资产的上传入口，调用 `POST /api/projects/{id}/assets/narration`，仅登记用户选择的 `.mp3`、`.wav` 或 `.m4a` 文件（上限 200MB），不会调用语音服务，也不会自动生成字幕；SRT 仍需另行上传。
- 两条接口相互独立：`/narration` 是自动生成动作，`/assets/narration` 是通用资产上传动作。修复或调整任一入口时，必须保留这两个路由的回归测试，避免末尾同名造成误分流。

### 素材库与电影混剪

1. 把电影、B-roll、图片分别放到媒体目录的 `originals/movies/`、`originals/broll/`、`originals/images/`。
2. 在设置中填写「素材库目录」「媒体素材目录」、FFmpeg/FFprobe，以及视觉/embedding 地址、模型与密钥。混剪查询向量必须和建库时同一模型。Pexels/Pixabay 密钥未配置时仍可本地建库。改 embedding 后若提示需要重启，必须重启，否则混剪仍按标签池选片。
3. 首页点「素材库」→「开始建库」。本机会扫描 `originals`、切镜抽帧、视觉打标和向量。进度看「就绪镜头」；识别全失败会提示，不要只看“就绪”。失败镜头可单项重试（会再跑建库）。也可搜索 Pexels/Pixabay 或上传本地文件。未知许可只标本地草稿可用，**不能当成公开发布授权**。
4. 「开始风景混剪」打散 `media_index` 里的风景/城市/财经，并混入 `catalog.db` 的 B-roll（计划里会有 `scenic_mixed_pool`，不按口播对画面）。「开始电影混剪」才按口播从 `catalog.db` 检索（标签 + 向量），不回退旧风景索引。详见 [混剪自动选片](montage-catalog-matching.md)。
5. 完整电影和原音轨不会上传；云端视觉请求最多带每镜 2–3 张低清关键帧。
6. 工作台「本次混剪计划」只描述这一条视频的配额和选用结果，不是全局素材库状态。

### 云机建库并回本机

控制台不必装到云机。把 `catalog-builder` 拷到云机，电影仍按上面的约定目录放好，然后：

1. 云机：`go run .\cmd\catalog-builder`（或直接运行编好的 exe）。远程桌面里打开 `http://127.0.0.1:2031`。
2. 填素材根、FFmpeg/FFprobe、视觉和向量接口后点「开始建库」。完成后点「下载结果包」。包里只有清单、`catalog.db` 和关键帧，没有电影、也没有密钥。
3. 把 zip 拷回本机。本机再运行同一个程序，在「本机合并」里填本机素材根和 zip 路径（或直接选文件），点「合并到本机」。
4. 本机原片必须已经在相同相对路径下，合并后的台账才能用于剪映成片。两台机器要用同一套视觉/向量模型。
5. 网站只听本机地址，不要改成对外网开放。密钥可用环境变量 `CATALOG_BUILDER_VISION_API_KEY`、`CATALOG_BUILDER_EMBEDDING_API_KEY` 覆盖。

### 字幕与特效

- 配音和 SRT 请自己生成或上传。混剪**不再往画面上画口播字幕**，排版还没过关，先整轨关掉。
- 不会导入整份 SRT 当一条轨，也不会建自动听写/文稿匹配轨。
- 不再画窗里的白色片头标题。板上金色标题和白色副标题还在。
- 画面按约 1.2 倍铺满，B-roll/电影按 **1.5×** 播放；图片有轻微 Ken Burns。
- 配额不够或匹配偏弱时，计划会写 warning 并降级，不会把任务卡在半成品。

1. 准备好连续文案、配音、SRT、账号背景图。
2. 启动混剪后，先生成受控工作区中的**明文草稿**。
3. 再登记到本机剪映目录并做路径/哈希验证；成功后才是正式 `mix_draft` 资产。
4. 登记失败时，若明文已在，可使用「只重试登记」，不必重跑 Codex。
5. 控制台**不会**自动打开剪映或微信视频号；请在本机手动检查。
6. 「打开目录」仅允许控制台所在电脑通过 `localhost` / 回环地址触发。

详见 [混剪登记说明](operations/montage-registration.md)。

## 8. 常见问题

下面只列高频入口；完整的错误原文、根因、排障顺序和禁止操作见 [常见问题与排障手册](operations/troubleshooting.md)。

| 现象 | 处理 |
|---|---|
| 刷新项目页曾出现 404 | 使用已包含 SPA 回退的构建；访问 `http://127.0.0.1:2030` 并强制刷新 |
| 外部聊天里有文案但项目不解锁 | 必须走正式任务产出 `continuous_script` |
| 配置改了没生效 | 看设置页是否 `restart_required`，需要则重启 |
| 手动上传配音显示网络失败 | 先确认控制台版本包含 `/assets/narration` 独立路由；该入口不依赖自动配音服务。MP3/WAV/M4A 需真实内容与扩展名匹配，且不超过 200MB |
| 混剪立即报 `No module named 'pyJianYingDraft'` | machine profile 的 `python_binary` 必须写为已安装 `pyJianYingDraft` 的 Python 绝对路径；保存后重启控制台。生成与登记两阶段都必须使用该路径，不能依赖启动终端的 `PATH` |
| 手机打不开剪映目录 | 设计限制；仅本机控制台电脑可触发 |
| 数据库在哪 | 控制台权威库：`video-console-data/console.db`；素材镜头库：设置里的 `catalog.db`（通常在素材根下）。不要误用根目录遗留的 `video-console.db` |
| 本机建库后风景混剪仍偏风景 | 风景线会混入城市/财经索引和 catalog B-roll，但不按口播选画面。要按口播用库内镜头请走「开始电影混剪」 |
| 买房/法拍对不到房子画面 | 当前财经库几乎没有住宅/法拍镜头，向量也只能对城市、办公、钱、K 线。要真房子先补 `originals/broll` 再建库 |
| 电影混剪立刻失败 | 库里没有就绪镜头，或原片相对路径对不上。电影线不会回退旧的 `media_index.json` |
| 建库提示识别全部失败 | 视觉/向量地址补到 `/v1`（只填主机名时程序会自动补），确认密钥后重试失败镜头 |

## 9. 备份建议

使用发布包内的 `console-maintenance.exe` 做一致性备份；备份目录必须在数据根之外。资产/媒体文件需按 manifest 另行备份。详见根 [README](../README.md)。
