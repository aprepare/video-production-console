## 1. 这是什么

本地单机视频生产控制台。Go 管鉴权、设置、SQLite、任务调度、图文批次、素材库；React 提供风景混剪看板和图文制作。不打开微信视频号，不托管成片上传。成片在剪映里导出。

默认地址 `http://127.0.0.1:2030`（本机常见也监听 `0.0.0.0:2030`）。权威库 `video-console-data/console.db`。根目录遗留的 `video-console.db` 不是权威库。

跑的是 `dist\video-production-console.exe` 时：改 Go / 前端必须停进程 → 必要时 `npm --prefix web run build:embed` → 重编 exe → **从仓库根目录**再启动。Vite `npm run dev` 的页面不是 exe 里那份。

首次安装（库里还没有管理员）必须先设：

```powershell
$env:VIDEO_CONSOLE_INITIAL_PASSWORD = "你的初始口令"
.\dist\video-production-console.exe
```

已有管理员后不再读这个变量。首次登录后立刻改密。不要把控制台暴露到公网或公共 Wi-Fi。

### 1.1 只有一套程序

自己用和以后发给商户的是**同一个程序**（本分支 `codex/video-production-console`），区别只在数据和配置：商户那边是空数据库，模型/接口/密钥用「配置码」一次导入，剪映等本机工具自动检测（见 §2.2「开箱配置」）。

8 月的「伙伴便携版」（分支 `feat/partner-exe-rollout`，安装包 0.1.x/0.2.0）停在 2026-08-22，没有之后的任何功能，配套网关 `:2443` 当前不在线，**不要再发**。它的网关（按伙伴发码、停用、限流）以后做商户计量时可以复用。

## 3. 怎么用

### 3.1 风景混剪（日产主路径）

1. 打开控制台即风景混剪看板。打开或新建项目（项目属于账号）。右上角可切到图文制作。
2. 粘贴同行原文 →「保存原文并开始二创」。写入 `source_script`，创建 `remix.standard`。
3. 二创**硬切** OpenAI 兼容接口（设置「二创服务地址 / 二创模型 / 二创 API 密钥」），不走 Codex CLI。模型名原样发送，不剥 `cursor-`。
4. rewrite 默认版本戳：`语感回流 2026-08-25 批注回流2`（`internal/agentruntime/openaicompat/prompts_writer.go` `RewritePromptStampStable` / `buildWriterPromptStable`）。成功标准四条：前 3 句与原稿同一件事且第一句就砸事、禁止铺现场；原稿开场已经最狠就贴着原文开场金句，禁止为换说法写软；答案继续藏；2.05万亿写成两万亿，但 0.95%、950块、万分之不要转成全中文；宁可冲不要写得好看，狠和懂打架选狠。卖课在方向判断后再补两三句，仍禁止空收尾（「就这些」「就这样」「好了」「就说到这儿」等）。默认 rewrite **不跑**字面重合 40% 闸和质检模型返工，写完即交付。`rewrite_sharp` / `copy` 后处理本轮未改。落盘以 `continuous_script` 为准。
5. 连续文案就绪后**停住**，等操作员确认文案再点「生成口播稿」：`remix.spoken_lines`，写入 `spoken_script`。不要自动续跑口播。规则：一句一行、每行不超过 9 个字（只计汉字和字母，阿拉伯数字和标点不计）、中间无空行、行尾空格；中文年份和「百分之」改阿拉伯数字；大数字优先用阿拉伯数字；《财富觉醒方法论》不拆开。模型如果把 `<|eos|>`、`</s>` 这类结束符写进最后一行，`Format` / 字幕对齐 / 上屏都会剥掉，不能当正文进剪映。后续配音字幕按这些行切，不要恢复 `remix.spoken_format`。口播稿就绪后仍自动标字幕关键词（失败回落本地词表）。项目资产里有「字幕关键词」卡：点「查看」按口播行展示红/金标注，可增删后保存；「重标关键词」只出现在这张卡上。保存走 `POST /api/projects/{id}/assets/caption_keywords`，会让已有混剪草稿失效。
6. 「生成配音与字幕」→ `POST /api/projects/{id}/narration`（火山 TTS + 词级 SRT）。配音读口播稿，不重写 `spoken_script`。手动上传走 `POST /api/projects/{id}/assets/narration`，不自动出字幕。两条路由不能抢占。
7. 「开始风景混剪」→ 本机 `montage-script-run` → Go 写 `production_plan.json` → Python skill 造明文草稿 → `montage.Coordinator` 登记剪映。
8. skill snapshot 含计划版本 `2.0` 时走 `BuildV2`。口播字幕轨 **打开**：行级 SRT 一对一上屏（`spokenCaptionsFromLineCues`），不再把多行粘合后按字切开。判定按口播稿内容字预算（汉字+字母，数字不计），带 `1.45%` / `2023年` 的行仍走一对一。风景任务 notes 为 `scenic_mixed_pool`：打散 `media_index` 风景/城市/财经并混 catalog B-roll，**不按口播对画面**。
9. 审核可「重做混剪」（再发一条任务，不删旧草稿）。发布文案来自最近二创结果。

### 3.1.1 文案创作台（原进化台）

风景混剪看板顶栏「设置」前的「文案创作台」进入 `/remix-lab`。左侧历史，**中间是工作流画布**（n8n 式节点图，React Flow），右侧智能体只出草案，点确认才改库、改工作流、开跑或设为日产二创。设置页「二创提示词」不再选锋利/copy，只显示当前由文案创作台采用的那一套；未采用时仍是 `语感回流 2026-08-25 批注回流2`。

写手成稿的完整链路：机械自检（10字连抄+篇幅）→ **审稿agent首轮终审**（规范清单：开头钩子、数字口语化、日期降级、互动段四字吉利话、课尾150-250字无下条预告、AI味、发布字段规格；只修违规处，产出 `draft_v1.json` 初稿留档和 `review.json` 结论）→ 落库。已完成的运行进结果工作区：双栏对照写手初稿与当前定稿；正文、长标题、短标题（恰好3条：第1条=混剪板标题、第2条=副标题）、描述（3条）、话题（4-5个）、CTA 全部可编辑增删，「保存修改」原样入库不做归一化。「按批注打回重做」把批注交给审稿agent再走一轮（run 回到生成中，完成自动回填修订稿）。「导入混剪（新建项目）」= 建项目 + 整包写手 JSON 交给 `assets/continuous_script`（后端拆正文并写 `publishing_package.json`，混剪板标题读 `short_titles[0]/[1]`），导入后项目里口播稿自动生成，配音、混剪照常在工作台点。「采用到项目」保留旧行为：只写已有项目的 `continuous_script`，不新建项目，不导入 titles。原创文案模式尚未接入（待定方案）。

### 3.4 图文视频（已屏蔽）

界面入口已关掉，旧 `/image-videos` 会回到风景混剪。后端和草稿脚本仍保留，后续再开。不要用这条线做当前日产。

原先产品设计（未对用户开放）：粘贴完整口播，选账号，选「图片视频」或「图生视频」。

服务端流程：

1. 配音（火山 / AuraSTD，与混剪同一套 TTS 设置）。
2. 按词级 timing 切镜头：前 30 秒每张目标 4.3–4.6 秒，之后每张至少 6 秒。张数由口播时长决定，不受 18 限制，硬顶 60。
3. 文本模型为每段写生图提示词（赤墨风、9:16、中文标题印在图内）。模型失败则本地兜底提示词。
4. 并发生图。图片齐后自动开 `imagevideo` 作业。
5. **图片视频**：图片 + 轻推拉/淡入淡出，无字幕轨、无可编辑标题。
6. **图生视频**：`grok-imagine-video-1.5`、480p、24fps、6/10/15 秒档、最多 6 路并发。失败**不会**降级成图片视频。
7. 全部镜头成功才构建并登记剪映草稿（内置模板 `jianying-image-video-v1`）。登记失败可单独重试，不重做配音和生图。

当前本机日志常有 `image_video_ffmpeg_not_configured`：图片视频仍可测，图生视频要先配 FFmpeg/FFprobe 和 Grok 视频接口。测试用本仓库 exe，不要用伙伴 0.1.15。

API：

- `POST /api/image-videos` 创建并后台跑（202）
- `GET /api/image-videos` 只列出 `run_mode=video` 的项目
- `GET /api/image-projects` 不包含图文视频项目
- `POST /api/image-projects/{id}/image-video-jobs` 仍可用于已有图片的作业（图文视频工作室在图片齐后会自动调）

### 3.5 素材库

电影/B-roll/图片放进 `media_root/originals/{movies,broll,images}/`。风景混剪看板「素材库 → 开始建库」跑完整三步：扫描 → FFmpeg 切镜抽帧 → 视觉打标 + 向量。看 `ready_shots`，不要只看 `state=ready`。识别全失败会记 `analysis_all_failed`。

### 3.6 剪映登记

生成明文草稿和登记到剪映是两步。明文在、登记失败时用「只重试登记」，不要重跑整条混剪。控制台不自动打开剪映。「打开目录」只允许本机回环浏览器触发。

machine profile 的 `python_binary` 必须是已装 `pyJianYingDraft` 的绝对路径；保存后重启。不要依赖启动终端的 PATH。
