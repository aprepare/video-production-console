# v3.14 内容推进与人工定稿

系统二创提示词与运行代码已更新，并在本地 2030 服务生效。未调用真实写手/参考/审稿模型，未生成新项目或启动混剪。

## 具体变化

| 位置 | 原行为 | 本轮行为 |
|---|---|---|
| 参考模型、写手、审稿的共同规则 | 悬念延后、新追问也算推进 | 开头尽早兑现具体解释；回应前一层疑问后再引出下一层 |
| 口播文笔 | 情绪与悬念要求较多，具体表达指导不足 | 谁做了什么、因果及观众得失；长短句交替，删除空泛感慨与重复催促 |
| 全文及课尾 | 原文0.8～1.1倍，长稿课尾400～550字参考范围 | 取消固定比例和课尾范围；用户指定长度是写作目标，最终人工取舍 |
| 中段、结尾 | 祝福互动及课尾规则 | 保留简短自然祝福；逐篇重写承接、学习价值与橱窗动作，避免重复拖长 |
| 工作流 | 写手→机械自检→审稿 | 写手→审稿；旧图按节点类型桥接，支持自定义ID |
| 运行与续审 | 重合率、篇幅、数字锁词、标题描述检查及返工；修订不足70%弃用 | 删除生产调用，不生成阈值提示、自动补写、机械警告或自检产物 |
| 导出发布包 | 截短描述、补标题、填话题，自动替换课名 | 封装模型字段，保留供人工编辑；提示词仍要求正确课名《财富觉醒方法论》 |
| 手工保存/导入 | 至少40字 | 正文非空即可；字数显示保留 |

保留JSON解析、非空正文、模型返回结构等运行校验。审稿通道或结果解析失败仍保留待审稿并记录错误，沿用此前重试行为。旧机械帮助函数和兼容字段保留供历史格式与旧单测使用，生产Run/Review/交付不再调用；它们的存在不代表启用了检查。
