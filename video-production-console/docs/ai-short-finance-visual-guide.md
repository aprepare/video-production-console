# AI短片：财经视觉制作（2026-09-05）

## 使用顺序

1. 在「AI短片」选择「财经解说」，选择账号、拆分镜模型、生图模型、A生活纪实或B温暖明亮。生图模型可直接填写，留空使用输入框提示的后台默认值；模型需由 AI 短片当前中转接口支持。
2. 新项目默认9:16竖图全幅、轻柔运动、下方字幕、关键词高亮与独立标注。旧项目继续使用原横图底板；可手动切换。
3. 拆分镜后，逐镜看原句、配图意图、画面类型、主体、场景、运动和实际生图提示词。
4. 点「改描述」可调整这些内容，也可增删关键词、改变分类，或清空重点标注。
5. 生成图片，查看字幕位置示意与运动预览。预览用于检查构图，最终计时以实际配音为准。
6. 点「配音并进剪映」。图片按实际旁白时间轴铺开；画面运动、旁白、BGM、字幕、重点标注进入可编辑轨道。完成后页面提供字幕时间轴与SRT下载。

## 如何从文案提炼画面

原句 → 具体对象 → 变化或矛盾 → 画面要说明什么 → 可见主体、动作与环境。

例如原句「存款到期之后，先把条件问清楚」：

- 对象：存款资料；变化：到期、重新比较；观众要看懂：先比较条件再决定。
- 画面类型：对比关系。主体：两份并排摆放的存款资料。
- 场景：普通家庭木桌上的两份资料、一本合上的存折和一支笔，自然日光，近景，纸面不生成可读文字。
- 运动：静止或轻微推近。关键词：存款、条件。标注：先看清条件（可空）。

「家庭」不再自动等于一家人的合影，「财富」不再固定等于金山，「机会」不再固定等于发光的门。人物、物件、环境按文意选择；人物镜表现行为关系，物件镜表现细节，环境镜交代空间；不预设人物或静物优先。段内检查避免全人物或全静物，保留语义上必要的例外。生图代码不再因关键词未识别到人物而自动全面禁人。纪实配图是内容示意，不冒充新闻现场。

## 字幕与重点标注

字幕按分句展示，过长时再折分；金额、年份、百分比和《课程名》不从中间拆开。关键词从旁白原词中选0～3个：数值、概念用金色，风险用浅红。每个词和正文在同一条字幕素材中，可在剪映继续逐字改。

重点标注是另一个文字轨，位于画面上部，每镜开头最多显示3秒。只用于重点转折、对比或总结，可随时关闭或清空；不强迫每镜都标注。页面保存模型给出的标注，内容由用户审阅。

## 修改后要重跑什么

| 修改内容 | 后续操作 |
| --- | --- |
| 整篇口播原文 | 保存后重新拆分镜 |
| 生图模型 | 保存后用于后续生成；已有图片保留，可逐镜点「重生图」使用新模型，无需重新拆分镜 |
| 画风、横竖布局、主体、场景、配图意图 | 保存后重生受影响图片，再组装 |
| 单镜旁白 | 保存后重新组装；配音按变更后的原句生成 |
| 图片运动、字幕位置/大小、关键词、重点标注 | 保存后重新组装，复用图片 |

新图片、配音和草稿都另存版本，旧草稿继续引用旧素材。用户主动删除项目仍会按原有删除功能清理项目素材。

## 实现与验证边界

图片请求同时使用当前转接接口的size字段，并为Grok Imagine补充aspect_ratio字段（[xAI官方画幅参数](https://docs.x.ai/developers/model-capabilities/images/generation#aspect-ratio)）。全幅请求9:16，底板请求16:9；上游返回的实际尺寸还需以生成结果为准。

静帧动态是关键帧推拉平移；图片和视频统一顺序排列在一条「画面」主轨。柔和叠化采用剪映原生转场（effect 322577 / resource 6724845717472416269），通常约0.3秒，短镜头自动缩短，挂在前一个片段上。配音、字幕起止和总时长保持不变，转场的实际呈现由剪映及其资源加载决定。旧的双轨草稿保持原样，重新组装会另存单轨版本。

## 开场节奏与Grok视频（2026-09-05）

顶部「接口与并发设置」打开「图片／视频接口」弹窗：图片和视频分别填写Base URL、API Key、并发数，点击「保存图片／视频接口」。接口配置对所有AI短片共用，下一轮生成读取新值；模型名称仍按项目保存。视频模型输入始终显示，不再要求先开启开场视频才出现。

URL留空沿用二创接口；独立URL使用独立密钥，换URL会清除对应旧密钥，避免误发送。密钥使用当前Windows用户的DPAPI加密保存，页面只返回是否配置，不回显密钥。当前请求协议仍要求服务商兼容图片生成与Grok视频任务接口，填写URL本身不会转换不同供应商的私有协议。

图片默认20路、视频默认6路，分别可填1～64。不同镜头可并行进行生图与生视频，同一镜需先完成参考图；视频从提交到等待完成共占一个并发名额。限制跨项目共享。已开始的任务保留启动时设置。视频任务保存所属URL，避免更换接口后向新服务查询旧任务编号。

在「画面与字幕」选择「开场AI视频」的前30秒或前60秒，并在「生视频模型」填写 `grok-imagine-video-1.5`。保存后生成，或逐镜使用「只重生视频」复用已有图片。视频默认关闭，开启后会产生上游视频生成费用；后半段继续用图片。

「约前30秒加密分镜」让拆镜模型优先把开场分成约2～4秒的小镜头，属于节奏指导，具体时长以配音为准；旧项目启用该设置后需要重新拆分镜。单纯调整叠化只需重新组装，单纯启用开场视频可复用当前分镜和图片。

开场视频范围按实际配音时间确定，跨越30/60秒边界的镜头在边界切回图片。每镜请求6、10或15秒，再按旁白长度裁切/适配；视频自带声音静音。镜头卡保存视频、动作提示词并可播放预览。已有素材文件与草稿保留。

真实接口测试已成功：6.04秒，720×1264，H.264。转接接口使用 `POST /videos/generations`、整数 `seconds` 和 `input_reference.image_url`；参考图先缩小并压缩，规避请求体大小限制。测试文件：`artifacts/grok-video-probe/grok-video-portrait-test.mp4`。没有自动运行整条付费生产任务。

等待超时后保留视频任务编号，「继续查询视频」复用原任务；明确失败的任务允许重提。提交结果不明时暂停自动重提，核对API后台后可点「重新提交视频」。程序中断后的运行状态会恢复为可续跑状态，保留素材和任务编号。

已做Go模块/API测试、前端组件测试、类型构建、真实pyJianYingDraft离线构建和浏览器交互验证。测试只使用临时素材及测试目录，未触发付费生图/TTS，未在用户剪映目录注册测试草稿。实际模型画质和剪映内最终观感需用下一条生产短片确认。

## 分镜工作台操作布局

已创建项目的顶部操作区集中显示生图模型、开场视频范围、视频模型、保存、拆分镜、生成及组装按钮。桌面滚动时工具栏固定在顶部。左侧「文案与画面设置」默认折叠；接口、密钥与并发通过顶部按钮打开独立弹窗，Esc可关闭。分镜采用紧凑预览尺寸，窄屏自动换行。新建短片的模型与画面选项折叠，优先填写账号和文案。

## 分镜思考强度与导出进度

「文案与画面设置」中的分镜思考强度支持none/minimal/low/medium/high/xhigh，默认low，保存后用于分大段与拆分镜；实际支持程度取决于模型与接口。财经生图不再以首图作为后续参考，避免重复首图人物和构图，寓言角色参考保持原样。

配音与草稿导出期间，顶部显示配音、时间对齐、组装草稿、导入剪映四个阶段，以及已用时。阶段进度来自后台和草稿脚本事件，不代表耗时百分比；成功后显示草稿名称，失败保留错误及所在阶段。
