# 二创工作区 · 开工说明（v5.0）

> 新对话第一句：「读 二创工作区/agent.md，然后 ……」。读完本文再读 `经验库/` 00、01、02、03、04、06（做画面才读 07），再动手。
> 本文是入口和总纲，规则正文在 `经验库/`，参照材料在 `参考库/`，每篇稿子在 `项目/`。
> **v5.0（2026-09-10）核心策略：锁定头尾作用、深度重构中段。旧版见 `_归档_v4.2.1/`。**

## 1. 这是做什么的

财经视频号二创：拿一篇对标口播原文，写一篇同题、同一份观看期待、中段表达和组织全新的口播，结尾自然接《财富觉醒方法论》（五块钱，主页橱窗）。

- 观众 **45～65 岁、关注财富和家庭选择的普通人**：第一句 3 秒听懂，用词具体，不用抽象词；例子只用每天摸得到的（菜钱药钱、红白事、工地厂里、带孙子、街口小店、白送鸡蛋的讲座），不用中产退休场景（旅游跟团、办卡、同学会、柜台理财）。
- 语言中文，像当面聊天，听一遍能懂；专业词第一次出现用一句大白话解释。
- **一个写手一次做完纠错、拆解、改写、自查**，不设独立策划/审稿节点，不输出 A1～A5 之类术语和分析过程。
- 先在工作区把稿子打磨稳，用户自己导入混剪控制台出剪映草稿。

## 2. 核心方法：三个区（v5.0 最重要的一节）

拿到原文先纠错（错字、同音字、标点；事实有疑点**不凭记忆改**数字、人物、政策），再把全文分成三个区：

1. **锁定区＝黄金开头**：默认开篇前 **3 个完整口播句**逐字保留（第 3 句没说完整就延到第 4 句）。不换开场切口、不重选候选、不改写成资讯或科普，只纠错和必要的口播顺气。**用户指定锁定范围时以用户为准。**（细则 01）
2. **重构区＝中段**：这是改写力气唯一该花的地方。保住影响结论的事实、人物、时间线、精确数据、比较条件、核心观点和对比框架；但禁止照抄独特整句、禁止逐句同义改写、连续 3 句沿用原文句式就重组该段。至少组合 3 种重构方法。（细则 02）
3. **闭环区＝结尾转化**：分三种情形——①原文推的就是我们这门课且匹配：产品价值、购买指令、末尾互动尽量逐字留，只纠错；②原文推别的书/课/服务：保留它"为什么需要→产品怎么承接→行动指令"的作用、节奏、情绪，替换成我们的课名、价格、入口、真实卖点，不照搬同行商品能力；③原文没课尾：用简短自然的承接补上学习价值和橱窗动作，不让正文突然换题。（细则 03）

**互动钩子**：原文已有的有效互动（提问、让评论、让收藏等）连同位置一起保留，不挪到统一位置、不另造一套；和我们账号/商品/事实冲突的部分才替换。**原文没有互动就不硬加**；我们的四字财运祝福，原文没有时默认不加，最多在中段矛盾讲完后轻提一句（用户 09-10 定）。

## 4. 每篇稿子怎么走

### 第 0 步 收原文 + 纠错
- 原文存 `项目/YYYY-MM-DD-主题/原文.md`（用 `模板/原文头.md`），正文原样保留；转写错别字、同音字、明显标点错误记在头部"备注"，成稿里用正确写法。
- 事实疑点不凭记忆改，保留原文口径，必要时用材料撑得住的限定表达。

### 第 1 步 内部拆解（填拆解卡，不等确认）
内部想清六件事（写进拆解卡，不写进口播）：①原文调动了什么需求/心理；②开头用了悬念/反常识/痛点/反差/机会里的哪种；③抽象观点落在哪些真实的人、事、数字、细节；④一句话单点核心（全文要讲清的那一个问题）；⑤情绪爆点在哪、由什么得失触发；⑥观众怎么从知道、感兴趣走到愿意行动。
同时标三区：锁定区是哪几句、中段有哪些必保事实和爆点、结尾走①②③哪种情形。
- 可参照 `参考库/自家爆款成稿/` 和 `爆款模式库.md` 同类机制，只学机制不抄句；模式库里"算法只推给命运好转的人、窗口只剩几天、评论换独家干货"这类不迁移。
- **默认直接往下写，不停下来等用户选开头**（开头是锁定的，没有候选可选）；用户说"先看拆解/只分析"才停。

### 第 2 步 成稿
- 锁定区逐字落；中段按 02 用至少 3 种重构法重写，每段给新事实/解释/对照/有依据的推论，先答上一问再引下一层；结尾按 03 情形处理。
- 开头留下的问题，正文要答到原文材料能撑的程度，不反复吊胃口、不把答案全推给课；不引入原文没有的赛道、产品、资产名。
- **同一套标准直接出稿**：不再为不同账号换入口/证据组/场景/祝福/锚定做"裂变"，模型每次发挥即可（用户 09-10 定，取消 v4.2.1 的多号裂变和 12 字连片重合考核）。一篇原文要发几个账号就出几篇，都按本规则正常写。
- 保存成稿（带成稿头）。

### 第 3 步 发布包
每版一份发布包（见 06）：大标题若干候选标推荐（≤12 字、无逗号、可走损失/反差/命运感力度档）、描述 1 条、标签 2～3 个、置顶评论。

### 第 4 步 批注与调优
- 用户批注按局部改：开头不满意——锁定区原则上不动，先确认是不是用户要改锁定范围；中段/结尾哪里不满意改哪里，不整篇重来；"再来一版"才重写。
- 每次改动另存新版本，并在该项目 `批注与调优.md` 记一行：时间、批注原话、改了什么、结论。
- 同一问题第二次出现，写回 `经验库/` 对应文件，带日期和来源。

## 5. 规则总纲（细则在经验库）

优先级：**保住原文让人继续看的期待和情绪冲击 ＞ 中段每段有新内容 ＞ 口播顺口 ＞ 篇幅。**

- **篇幅**：讲完为准，宁短勿水，不为凑字重复、不堆套话；与原文字数 ±10% 只作参考不是硬指标（用户 09-10 定）；正文含课尾，统计汉字+字母+数字，不计空白、标点、标题、分析。
- **力度守恒**：原文站不住的强句（编的数字、绝对化、收益承诺、操作指令）删掉后，同一位置补一个合规的强句——处境场景、真实反差、追问、引号原话，不能删完留白；钩子和金句数量不低于原文。情绪从处境来，不把整篇改成平淡叙述。
- **不做的审核动作（用户 09-10 定，省时间省 token）**：不联网做事实核查、不跑平台红线/合规预审、不做"风险提示"把关——**事实与合规由用户亲自终检**。写手只守写作底线：以原文为事实来源，不新增原文没有的数字/人物/亲历/收益承诺，数字保留原文量级口径。
- 课名《财富觉醒方法论》、五块钱、主页橱窗；只承诺课纲里有的（见 04），不报节数、不写"不是教你……"、不羞辱观众。
- 结尾默认**不加关注引导**（用户 09-10 定）；挂车/不挂车动作句区别见 03。

## 6. 写回规则（经验怎么沉淀）

- 开头 → 01；中段/推进/情绪/互动 → 02；结尾/价格/转化 → 03；课程资料、数字口径 → 04；发布/标题/评论 → 06；流水账统一记 05。
- 每条新规则带日期、来源（哪篇哪次批注）、状态（用户认可 / 已发布有数据 / 待验证）。一次性口味只记该项目批注表，用户说"以后都这样"才升级为规则。
- 写进规则的是作用和判据，附一两句样品并标"样品句不得原样出现在成稿"；不把整段成稿固化成模板。

## 7. 交互约定

- 默认直接交完整成稿+发布包，不逐步请示、不贴分析长文；交付时给文件路径和一两句说明（锁定区怎么落、结尾走哪种情形）。
- 用户批注优先级高于本文件和经验库；用户当前要求优先于历史规则。
- 不为"像 AI"删掉有作用的反问、短句、情绪句；避免"在这个充满……的世界""让我们一起""值得一提的是"这类套话和报告腔。
- 假设例子必须明说"假如/比如"；历史相似不写成结果必然重演。
