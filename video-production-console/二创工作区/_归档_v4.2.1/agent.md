# 二创工作区 · 开工说明

> 新对话第一句：「读 二创工作区/agent.md，然后 ……」。读完本文再读 `经验库/` 五个文件，再动手。
> 本文是入口和总纲，规则正文在 `经验库/`，参照材料在 `参考库/`，每篇稿子在 `项目/`。

## 1. 这是做什么的

财经视频号二创：拿一篇同行的爆款口播原文，写一篇同题、同一份观看期待、但表达和组织全新的口播，课尾自然接《财富觉醒方法论》（五块钱，主页橱窗）。观众基本是 **50 岁以上**的普通人：第一句要 3 秒听懂，用词具体，不用抽象词。

先在这个工作区（Cursor 对话 + 文件）把稿子和规则打磨稳，用户自己把成稿导入混剪控制台出剪映草稿。控制台里的自动流程（`internal/agentruntime/openaicompat/editorial_policy.go`，当前 v4.2.1）和本工作区同源；这里验证过的规则再同步进控制台，不反向。

## 3. 每篇稿子怎么走（三道工序，不在一个念头里干完）

### 第 0 步 收原文
- 把原文存进 `项目/YYYY-MM-DD-主题/原文.md`，用 `模板/原文头.md` 填元数据：来源、播放/点赞（如有）、钩子类型、原文里站不住的承诺。
- 在 `参考库/同行原文/索引.md` 加一行。
- 同一原文如果同行有 A/B/C 同源版本，一起存，避免只看单条改出撞稿（森林）。

### 第 1 步 拆解与参照（不写稿）
读三样东西，再填策划卡的「拆解」部分；同时联网核开头和课尾要用到的关键数字（默认，用户 2026-09-07 定），结果记在策划卡自审里，可复用的写进 `04-事实与红线.md` 的核查记录：
- `参考库/自家爆款成稿/`：看自己爆过的稿是怎么开头、怎么转、怎么收的。
- `参考库/爆款模式库.md`：找和本篇钩子同类的机制条目，只学机制不抄句子。同行的爆款也有毛病（算法只推给命运好转的人、窗口只剩几天、评论换独家干货），这些不迁移。
- 本篇原文，按森林的六问拆：①这篇真正想让观众相信什么；②开头为什么能留人；③中段靠什么让人继续听；④产品为什么能接上；⑤哪些句子最值钱、不能删（情绪资产，写完对照）；⑥哪些结构可以复用。再补：证明材料逐条列出、站不住的承诺、转折、课程关系。

### 第 2 步 框架与开头（不完稿）
- 三个入口不同的开头候选，都必须承接同一份期待；第一句直接说出期待，切身数字只能当第二三句的证据。
- 段落作用表：每段新增什么、回应哪个问题；最后一到两段正面回答主问题（答到原文材料能撑的程度）。
- 祝福评论位置、课尾五步各自的材料，都在这一步定，不到结尾即兴。
- 默认自己选定候选继续写；用户说「先看开头」才停在这里等选择。

### 第 3 步 成稿与自审
- 按 `经验库/00～04` 写全篇，三个钩子位置固定（3 秒钩子 / 中段钩子 / 结尾钩子，见 06），写完按 `03-课尾转化规则.md` 末尾的自审清单过一遍。
- 同一原文发几个账号就写几个裂变版本，互算 12 字连片重合率，**上限 35～40%**（用户 2026-09-07 22:22 定，原来 ≤15% 作废：留人比避重合重要）。**每写完一版立刻测**，再写下一版；连着写两版后半段最容易变成同一套词（09-07 版四版五首写互相重合 37%）。降重合靠换入口、换证据组、换场景人物、换三条和课尾材料、换锚定物；**不靠换比喻系统**——给每版套一副比喻骨架（老黄历/翻页、顺风/顶风、秤、换季、粮仓、温度计）是 09-07 七版被用户批"中间差点意思、留不住人"的直接原因，见 02。
- 保存成稿文件（带元数据头），策划卡另存。
- 交付时：给成稿文件路径、一段话说明入口选择和课尾衔接，不贴分析长文。

### 第 3.5 步 发布包与发布前审
- 每版一份发布包（见 06）：大标题 3 候选标推荐、描述 1 条、标签 2～3 个、置顶评论建议。
- 发布前审：按 `06-发布与评论.md` 的要点自查（投资建议式句子、收益承诺、导流话术、标题与内容是否相符）；装了 yuwen-publish-precheck 就跑一遍，结论附在发布包里。

### 第 4 步 批注与调优
- 用户批注按局部改：开头不满意就重出开头候选，不整篇重来；「再来一版」才换入口重写。
- 每次改动另存新版本，并在该项目的 `批注与调优.md` 记一行：时间、批注原话、改了什么、结论。
- 同一问题第二次出现，就写回 `经验库/` 对应文件（见第 5 节），不只改当前稿。

### 第 5 步 发布与复盘
- 用户导入控制台出草稿、发布后，把账号、日期、播放、完播、转化填回 `账号/账号与分发.md` 的数据表和成稿头的「状态」。
- 有数据的稿子才能升级成「参照」；没数据的只是「认可」。

## 4. 规则总纲（细则在经验库）

优先级：原文让人继续看的期待 > 每段有新内容 > 口播顺口 > 篇幅。四者冲突按此取舍。

- 开头：保住原文钩子的类型和力度，换入口和说法；第一句说出期待，不用利率、存款、利息数字起手；前三句里要有一个反差和一个问句。
- **力度守恒**（用户 2026-09-07 22:22）：原文里站不住的强句（编的数字、绝对化、收益承诺、操作建议）删掉后，同一位置必须补一个合规的强句——处境场景、反差、问句、引号里的原话——不能删完留白。成稿的钩子和金句数量不低于原文，逐句自数写进策划卡。不为合规把整篇改成叙述口吻：情绪从场景来（老伴半夜进医院先交的押金），场景完全合规。
- 正文：一条主线，每段有新事实/对照/因果；历史段各担一个作用，讲完接回眼前；主问题正面答到材料能撑的程度，只用原文材料和原文点到的方向。**比喻只做落点不做骨架**：一版最多一处一句话的短比喻放在结论上（"前些年轻得像纸，今天重得像砖"），不用一套比喻贯穿全篇，不写"这是黄历换掉的第一页""这是一半"这类只给比喻导航、不给内容的句子。
- 受众：50 岁以上的**普通人**——打工、开小店、种地、带孙子，退休金不高或没有。例子只用他们每天摸得到的（菜钱药钱、红白事的礼、彩礼酒席、孙子奶粉、工地厂里、街口小店关门、白送鸡蛋的讲座、储值卡），不用中产退休生活（旅游跟团、办卡、老同学聚会、柜台理财），见 00。
- 互动：全文一处四字祝福评论，放在一个矛盾讲明白之后，接回内容。
- 课尾五步：承接困惑 → 课程能做到的一两件事 → 价格锚定一次 → 用本篇历史反差做一次遗憾预演 → 橱窗动作 +（一家至少一人）+ 绑定本题后续的关注 + 最后一句回到橱窗。写成连贯的一段，**不用"第一、第二、第三"编号**，课不排成清单；读心带第二人称痛点三连，课说成"视频里来不及展开的那一步"，犹豫拆解列观众自己的小开销，见 03（2026-09-07 22:51、09-08 08:19 两次批注）。
- 红线：不编数字、机构、期限、名额、收益、人物、亲历现场；课名《财富觉醒方法论》、五块钱、主页橱窗、只承诺课纲里有的；不报节数、不写「不是教你……」；不羞辱观众；不用「宏观决定不了先管家里的钱」换题。
- 篇幅：不设硬下限，讲完为准，不为凑字加话；宁短勿水（完播比 10 分钟加权重要）；超过 2800 字就删。

## 5. 写回规则（经验怎么沉淀）

- 开头的问题 → `01-开头规则.md`；推进/换题/历史段的问题 → `02-正文推进规则.md`；课尾、价格、遗憾、关注的问题 → `03-课尾转化规则.md`；数字、口径、编造 → `04-事实与红线.md`。
- 每条新规则带：日期、来源（哪篇哪次批注）、证据状态（用户认可 / 已发布有数据 / 待验证）。
- 只写验证过或用户明确认可的；一次性的口味调整只记在该项目的 `批注与调优.md`，用户说「以后都这样」才升级为规则。
- 不把整段成稿固化成模板；写进规则的是作用和判据，附一两句样品，并标明「样品句不得原样出现在成稿」。
- 复盘流水账统一记 `05-复盘日志.md`，一行一事。

## 6. 交互约定

- 默认直接交完整成稿，不逐步请示；用户明确说「先看开头」「只分析」时停在那一步。
- 用户给的批注优先于本文和经验库；与事实或课程资料冲突时说明依据再改。
- 不为凑字数加话，不为「像 AI」删掉有作用的反问、短句和情绪句。
- 数字核查默认只核开头和课尾的关键数字；不凭记忆替换事实，原文数字保留量级和口径。
- 口播人设句（"刚开完银行内部会议"）允许，不落到具体人物、对话、来源。
- 同一原文要发几个账号，就出几个裂变版本（入口、案例顺序、祝福词、锚定物都不同），见 `账号/账号与分发.md`。

## 6.5 换模型做对比测试时，怎么发第一条消息

同一个工作区、同一套规则、同一篇原文，让不同模型各写一版，再由主模型对比分析。测试稿只用来比，不改经验库，也不改已有文件。给对比模型的第一条消息模板（原文已在项目目录时）：

```
读 二创工作区/agent.md，再把 二创工作区/经验库/00～06 七个文件全部读完，然后按 agent.md 第 1～3.5 步给账号「认知漫步」写一版二创。

原文：二创工作区/项目/2026-09-06-人民币第三次换锚/原文.md
同题已有六版成稿在同一目录，只读它们用来避开重合（开头入口、证据组、祝福词、课尾锚定物、三件事都要和它们不同），不要照抄任何句子。
挂车版（课尾动作句用 03 里的挂车版写法）。

交付到同一目录，文件名：
- 策划_2026-09-07_HHMM_<你的模型名>对话_认知漫步.md（用 模板/策划卡.md 的结构，含森林六问和三个开头候选）
- 成稿_2026-09-07_HHMM_v4.2.1_<你的模型名>对话_认知漫步_挂车.md（用 模板/成稿头.md 的头，正文纯口播）
- 在 发布包_2026-09-07_0150.md 末尾追加一节：大标题 3 候选（一句话 ≤12 字，标字数和推荐）、描述 1 条、标签 2～3 个、置顶评论。

写完自己做三件事并把结果写进成稿头的备注：①字数（不计标点）；②与六版的 12 字连片重合率；③用 ~/.cursor/skills/yuwen-publish-precheck 的 scan.py（--commercial --industry finance）跑发布前审，命中要改到 0。
```

原文是新的时，先让它把原文存成 `项目/YYYY-MM-DD-主题/原文.md`（用 模板/原文头.md），再走上面的流程，并在消息里把原文全文贴给它。

对比模型交稿后，回到主模型（Claude）说："读 二创工作区/agent.md，对比 项目/…/成稿_<模型>_认知漫步 和同目录 Claude 写的版本，按 01～03 逐条评，结论记进 批注与调优.md。"

## 6.6 让别的 AI 接手（了解思路、续写、评稿）时怎么发第一条消息

思路不在任何一个文件里，在三层：规则（本文 + 经验库）说"怎么写"；`批注与调优.md` 说"用户为什么这么要求"（每条规则的来历都在那里）；最新的 `_改1` 成稿是"写成什么样算对"的样本。让别的 AI 接手，就按这个顺序喂，最后才给任务。

**它能读文件时**（Cursor / Codex / Claude Code 等，打开的是本仓库），第一条消息：

```
先读 二创工作区/agent.md，再按顺序读 二创工作区/经验库/00、01、02、03、04、06 六个文件（做画面才读 07）。
然后读 二创工作区/项目/2026-09-07-钱越来越值钱/ 里的 原文.md、批注与调优.md，以及两篇 成稿_2026-09-07_2240_…_改1.md（天中观局、认知漫步）——这两篇是当前认可的写法样本；同目录 1400 那批是被批过的对照，看它们只为知道什么不对。
再读 二创工作区/项目/2026-09-06-人民币第三次换锚/成稿_2026-09-08_0810_…_云中观局_不挂车_改1.md 的课尾，这是当前的课尾样本。
读完先用三百字以内复述：观众是谁、三个钩子各在哪、课尾五步是什么、哪些是红线、这两天用户批过什么。复述对了再接任务。
不要改 agent.md、经验库、账号表和任何已有文件；新稿另存新文件，改动记进该项目的 批注与调优.md。
任务：……
```

**它不能读文件时**（网页版 ChatGPT / Claude / 豆包等），分两三条消息贴，顺序不能乱：

1. 第一条只贴一句："下面几条消息是一套财经视频号二创的规则和样本，先只读，不要回复，我说'开始'再动手。"
2. 依次贴：`agent.md` 全文 → `经验库/00` → `01` → `02` → `03` → `04` → `06`（这七个合计约 2.2 万字，一条消息贴不下就分两条）。
3. 贴 `项目/2026-09-07-钱越来越值钱/批注与调优.md`（约 4 千字，用户的判断都在这里）和两篇 `_改1` 成稿正文（各约 1.5～2 千字）。要它写课尾就再贴 09-08 云中观局改1 的课尾。
4. 最后一条："开始。先用三百字复述规则和受众，再做：……"。原文是新的，就把原文全文和你的账号、挂不挂车一起写在这条里。

不用贴的：`爆款模式库.md`（1.5 万字，只在要它拆同类钩子时贴对应条目）、`07-画面与分镜.md`（只做文案不用）、`账号与分发.md`（只在它要分配账号时贴）、旧版成稿。
