# 03 课尾转化规则

课尾五步按顺序，合计约 250～350 字。每步一两句，同一卖点不说两遍，价格最多出现两次。

## 五步

1. 承接：从正文最后一层实际困惑接过去（看懂这件事之后，自己那笔钱接下来怎么安排）。一两句，不重开一轮焦虑，不用"宏观决定不了，先管家里的钱"换题。
2. 课程：《财富觉醒方法论》，五块钱，主页橱窗，只在课尾出现。正面讲学完能做到的一两件具体的事（来自课纲，见 04），不报节数、不念目录、不写"不是教你……""不教……"。
3. 价格锚定，只说一次：五块钱和一件日常小东西比（一瓶水、一根油条一碗豆浆、一趟公交、一次凑单外卖），具体、口语，锚定物按本篇换，不每篇都是矿泉水。
4. 遗憾预演，只说一次：用正文自己讲过的历史反差做对照（当年看不上做外贸的、劝别人别背房贷的，回头看是同一种遗憾），落到"知道了不动，比不知道更亏"。不编期限、名额、原价，不说"窗口只剩几天"。
5. 动作：点开主页橱窗一句；可接"一个家里至少有一个人把这件事弄明白"；关注要绑定本题的具体后续（这轮便宜钱往哪松闸、政策一有动静第一时间拆），不说锁定推荐；最后一句回到橱窗（"橱窗里等你"）。
   **挂车版**（视频下方挂了课程商品）：动作句改成"点开视频下面这门课"放前面，"主页橱窗也有"留作备用，最后一句回到"视频下面"。成稿头备注写明"挂车版"，同一原文的挂车版和不挂车版课尾动作句不同，其余可相同。

## 2026-09-07 对照样本给的修正（同事挂车版 1 万播放 30 单，见 `参考库/对照稿/`）

- **三件事行为阶梯**从下一版起用：前两件是零成本自律动作（关掉朋友圈、卸掉游戏推掉饭局之类，按本篇换），第三件才是五块钱的课。它在五步里的位置是第②步之前，一两句带过。
  **不用"第一、第二、第三"编号写它**（用户 2026-09-07 22:51 批注，七版都用了"从今天起，做三件小事。第一…第二…第三，我主页橱窗里有一门课…"，被批"转化生硬""为什么都用这种形式"）。原因：正文里已经有一组"三条 / 三句话"，课尾再来一组编号，观众连听两张清单，课就成了清单的第三项，像念提纲；课的内容再排成"钱从哪儿来、到哪儿去、欠着谁的；哪些能动、哪些是底；……"又是一张清单。保留阶梯的机制（先答应两件不花钱的事，再接五块钱），但写成连贯的一段：从承接问句接"这几笔账不难算，难的是没人坐下来算"→ 两件今晚就能做的事，说清做完心里能有什么数 → "有数之后往下怎么摆，才是真正费心的"→ 课是这一步，用观众自己的场景说清课能帮他做到的一两件事 → 锚定物一句。同一原文多个版本的课尾段各写各的话，不套同一句式。
- **课尾用课纲第⑧节把课接紧**："这一轮的信号怎么看、自己家的钱 2026 年往哪调、先调什么"，比"自己那笔钱怎么摆"更贴正文的问题，而且课里真有。
- **归因翻转**放课尾第④步之后一句："不是你不努力，是站的位置不对。"
- 紧迫感只留不带日期的一句（"这一轮已经开始，早看懂早站位"）；不写月份、"两个月后"、"2026 年之内"。
- 仍不搬：把课说成揭晓"钱往哪流"的答案；命运推送句；具体日期或收益承诺。

## 用户自己库里验证过的机制（`参考库/爆款模式库.md` 结尾 9 条 + 自家爆款成稿）

- 读心开场：把观众心里的疑问替他说出来（"这事到底跟我有什么关系"）。
- 课 = 前文没来得及展开的补全。
- 小物价格锚定（酱油、奶茶、矿泉水、油条）。
- 卸学习压力：不念文件、不堆大词、就让你听懂。
- 犹豫拆解：列观众平时无意义的小开销（凑满减、刷礼物、停车超时）做对比。
- 身份升格：你已经不是观众，是准备上场的人。
- 知道了不动比不知道更亏。
- 一家至少一人听（把购买单位放大到家庭）。
- 归因翻转：不是不努力，是站的位置不对。
- 关注 = 持续陪跑，绑定"后面有新信号第一时间拆"。

按本篇取两三条，不全用。

**读心课尾怎么写才不软**（用户 2026-09-08 08:19 批"还是差点意思，去看爆款模式库的结尾钩子"，对照模式库结尾 2/5/7/8 得出）：读心不是一句"很多人心里有个问题"，要跟第二人称痛点三连——用本篇正文自己的意象写三句"你……"（存款越躺越薄 / 别人的钱换了地方你还守在上一个住处门口 / 知道开始了却不知道第一步往哪迈）；课要说成"视频里来不及展开的那一步"，让买课等于把刚才没听完的听完；犹豫拆解列两三样观众自己的小开销（直播间凑单没拆的、给孙子随手买的塑料玩意儿），收一句"花出去一点水花都没有"；价格说成门槛（留给真想理明白的人），不说成便宜；三批人结局排比 + "划走还是花五块钱"二选一放在遗憾前；关注绑成陪跑（家里多了一个替你盯着钱往哪流的人）。承接材料（定期几笔 / 能动不能动 / 余量）不要写成账目清单，揉进痛点三连里。样本：`项目/2026-09-06-人民币第三次换锚/成稿_2026-09-08_0810_…_云中观局_不挂车_改1.md` 课尾。

## 不迁移的东西

- 算法只推给命运好转的人、能量共振、划走就是丢自己的钱。
- 窗口只剩几天、名额、原价、限时。
- 评论暗号换独家干货。
- 羞辱观众（"缺的是五块钱还是缺脑子"）。
- 具体投资出口、收益承诺、学员成果。

## 样品（只学顺序和作用，样品句不得原样出现在成稿）

坏："道理都知道，可你连自己每个月固定支出是多少都没数过。"——为接课把主题换成记账，还教训了观众。

坏："专门用一整节课给你理清……教你全面梳理……建立四个无痛存钱技巧……不是教你炒什么买什么。"——报节数、念目录、否定式边界。

好（Claude 对话稿 2026-09-07 的五步）：方向是方向，你家那笔钱是你家那笔钱 → 课能帮你做两件事：理成一张看得懂的账、把该兜的风险先兜住 → 五块钱一根油条一碗豆浆 → 2001 年看不上做外贸的、2009 年劝别人别背房贷的，遗憾的是看见了没动，知道了不动比不知道更亏 → 橱窗、一家至少一人、关注绑定"便宜钱往哪松闸"、橱窗里等你。

## 自审清单（成稿后逐条过）

- [ ] 第一句说出了原文那份期待，不是数字资讯。
- [ ] 主问题在正文里正面答到了材料能撑的程度，没有换成"先理清家底"。
- [ ] 一处祝福评论，位置在矛盾讲明白之后，接回了内容。
- [ ] 课尾五步齐全，顺序对，价格 ≤2 次，锚定和遗憾各 1 次。
- [ ] 没有节数、目录、"不是教你"、期限、名额、原价。
- [ ] 没有原文没有的资产/产品/赛道名称，没有编人物和现场。
- [ ] 承接句、锚定句、遗憾句都是本篇自己的说法，不是样品句，也不是样品句的换词改写（"定期续不续 / 三五年用不着能动 / 给爹妈看病给孩子上学一分不能碰 / 余量够不够"这组承接材料属于云中观局版；其他版本要换自己的困惑材料，比如到期的钱往哪放、退休金和存款怎么分、要不要听子女的建议）。12 字重合率测不出换词改写，写完自己读一遍对照样品。（2026-09-06 gemini 稿照抄、09-07 Opus 稿换词改写，两次出现，定为规则。）
- [ ] 2500～2800 字。
- [ ] 同一原文若已有其他版本，入口和课尾锚定物与之错开。
